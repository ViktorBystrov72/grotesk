Video editing

Формат операций: start|end|prompt

Время можно писать как 75, 01:15 или 00:01:15.

Общий prompt задаёт общий стиль и контекст для всех операций. Операции по времени задают точечные изменения на конкретных отрезках видео.

Если нужен только точечный монтаж по таймкодам, общий prompt можно оставить пустым.

Выходное видео

Параметры ниже задают формат клипа после отработки пайплайна (разрешение, длительность куска одного прохода, «силу следования тексту»). Значения ширины/высоты и длины по времени подобраны под ограничения пространственного и временного VAE модели Wan в Lucy Edit.

Ширина кадра — сколько пикселей по горизонтали будет в сохранённом видео. Больше ширина → больше детализации и текстур, но дольше инференс и выше расход памяти (VRAM). Число в списке кратно {{ spatial_align }}: так устроено пространственное сжатие VAE; иначе возможны ошибки пайплайна или артефакты выравнивания.

Высота кадра — число строк пикселей по вертикали; вместе с шириной задаёт общую «тяжесть» кадра для модели. Те же ограничения кратности {{ spatial_align }}. Для экономии времени имеет смысл не раздувать оба измерения, если исходник низкий по разрешению.

FPS — сколько кадров в секунду в сохранённом MP4 при заданном числе кадров задаёт фактическую длину фрагмента (примерно: кадры ÷ FPS). Выше FPS → плавнее движение при той же длительности, но каждая секунда «весит» больше кадров для модели. Ниже FPS — экономия времени и нагрузки, иногда более «выразительное» по кадрам движение.

Число кадров за один проход модели — ограничивает, сколько кадров из фрагмента подаются в диффузию за раз (чанк времени): больше кадров → лучше согласованность длинного движения и контекста, но резко дороже по времени и памяти. Список выбран так, чтобы (число кадров − 1) делилось на {{ temporal_frame_rule }} — это временной шаг VAE; без этого возможны ошибки выравнивания по времени.

Classifier-free guidance scale — насколько жёстко результат привязан к текстам (общий prompt и подсказки операций): выше значение → модель старается буквальнее выполнить формулировки, возможны переусиленные цвета/детали и менее «естественное» поведение; ниже → больше свободы и плавность, но меньше точность к тексту. Диапазон на форме 1.0–20.0; по умолчанию 3.0 — разумный баланс между следованием prompt и качеством движения.
